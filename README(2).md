# Frontline 3D – Version 1.5.2

## Installation / Aktualisierung
Lade `index.html` in dein GitHub-Repository hoch und ersetze die bisherige Datei. Danach die GitHub-Pages-Seite mit Strg + F5 neu laden.

## Battle Pass
Der Freischalt-Button prüft die Credits, zieht 2.000 Credits ab und aktiviert den Battle Pass lokal im Browser. Der Fortschritt wird im lokalen Speicher des Browsers abgelegt.
