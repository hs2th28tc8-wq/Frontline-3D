# Frontline 3D – Version 1.5.1

## Starten
- `index.html` auf GitHub in den Hauptordner des Repositorys hochladen.
- GitHub Pages aktivieren: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Battle Pass
- Der Battle Pass kann jetzt auch im lokalen Offline-Modus freigeschaltet werden.
- Freischaltung kostet 2.000 Credits.
- Credits werden durch verdiente XP gesammelt.
- Fortschritt wird lokal im Browser gespeichert (localStorage).

## Hinweis
- Online-Funktionen wie Freunde, Lobby und Voice-Chat sind in diesem GitHub-Offline-Build nicht aktiv.
- Three.js wird über ein CDN geladen; zum Spielen ist eine Internetverbindung nötig.
